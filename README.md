# Hamad Alsheail — Diwan Alshams

A static portfolio site built from the *Hamad Alsheail Creative Portfolio* deck.

## Structure

```
index.html              landing page, split into Photography and Writing
photography.html        hero, about, Wa'atha' 1447 H, four photo series, contact
gallery.html            the wider archive — everything not in a series
writing.html            the Writing index with search (built by Jekyll from _posts/)
search.json             search index, generated by Jekyll
writing-search.js       Arabic-aware search on the Writing page
_posts/                 blog posts, one Markdown file each
_layouts/               base + post templates for the blog
_includes/              shared top bar, Instagram embed
_config.yml             Jekyll settings (GitHub Pages runs Jekyll on every push)
styles.css              all styling; palette and type carried over from the deck
script.js               lightbox (click a photo, arrow keys to navigate, Esc to close)
gallery.js              renders the gallery grid from the manifest
gallery-manifest.js     GENERATED — the gallery photo list
gallery-captions.json   captions, keyed by filename; edit this one
tools/build-gallery.py  regenerates the manifest from img/gallery/
img/                    21 photographs from the deck, resized to 1400px
img/gallery/            32 further photographs, resized to 1200px
```

## Adding gallery photos

Drop files into `img/gallery/`, add captions to `gallery-captions.json`, then:

```
python3 tools/build-gallery.py
```

A static page can't read a directory listing, so the photo list has to be
generated. The script prints any file that's still missing a caption — those
fall back to a tidied-up version of the filename.

## Publishing a post

1. Write it in Post Studio and export Markdown. The file is named
   `YYYY-MM-DD-slug.md` and starts with front matter:

   ```yaml
   ---
   title: "وعثاء الطريق"
   date: 2026-11-18
   lang: ar              # ar = right-to-left, Kufi titles, Naskh text; en = left-to-right
   slug: waatha-road     # the URL: /writing/waatha-road/
   excerpt: "One line shown on the Writing page."
   tags: [travel]
   cover: /img/posts/waatha-road/cover.jpg   # optional, shown 16:10
   instagram: https://www.instagram.com/reel/XXXX/   # optional reel under the post
   draft: false          # true = hidden from the Writing list
   ---
   ```

2. Put any images in `img/posts/<slug>/` (about 1400px wide).
3. Upload the `.md` file to `_posts/` (GitHub web or mobile app: Add file → Upload).
   The site rebuilds in about a minute.

A reel can also go inside the text, anywhere in the body:

```
{% include instagram.html url="https://www.instagram.com/reel/XXXX/" %}
```

## Running it

The blog needs Jekyll to build:

```
gem install jekyll -v 3.10.0 kramdown-parser-gfm
jekyll serve
```

Then open <http://localhost:4000>. The home page and gallery still work from
any static server, but `/writing/` only exists after a Jekyll build.

## Notes

- Type is **Bricolage Grotesque** (loaded from Google Fonts, as in the deck),
  with **Noto Kufi Arabic** for the Arabic text.
- Colors are taken from the deck's XML: paper `#EDE8E5`, body ink `#242424`,
  and the deck's amber `#FFA51F`. Headings and labels on paper use a darker
  amber, `#A85A00` (`--accent-text`), because `#FFA51F` on paper is too low in
  contrast to read; the bright amber stays for accents and dark backgrounds.
- Arabic posts: **Noto Kufi Arabic** for titles, **Noto Naskh Arabic** for text.
- Images are lazy-loaded below the fold and open in a lightbox with captions
  drawn from their alt text.
- The gallery photos came from the "Top photos" Google Drive folder. 15 of the
  47 were already used in the deck, so they were left out of the gallery to
  avoid showing the same frame twice.
